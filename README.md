## 1차 배포본 (2026.10.26)
- 페이지 안의 [확인 필요] 표시와 빈 사진 자리는 모두 정리했습니다.
- 공개 뒤 이어서 할 일
  1. 카카오톡 채널 채팅 주소 → `js/config.js` 의 `kakao` (넣으면 카톡 버튼이 나타남)
  2. 견적 신청서 접수 주소 → `backend/README.md` 순서대로 Apps Script 배포 후 `quoteEndpoint` (넣으면 신청서가 나타남)
  3. 주소가 정해지면 `python tools/set_domain.py https://주소`
  4. 사무실·준공 현장 사진이 생기면 `images/ref/` 사진 교체

## 측정
`data-track`이 붙은 버튼을 누르면 `dataLayer`에 이벤트가 쌓입니다. GA4나 구글 태그 관리자를 `<head>`에 붙이면 바로 수집됩니다.
- `tel_click`, `kakao_click`, `quote_click` (+ 누른 위치 `location`: header, hero, bottom_bar, final, footer 등)
- `form_start`, `form_step`, `form_submit`, `form_abandon`, `before_after_use`, `faq_open`

## 전후 사진 구도 맞춤 (2026.10)
청소 전후 사진은 '후' 사진을 '전' 사진 구도에 맞춰 변형하거나(15쌍, 특징점 매칭), 피사체 크기와 위치가 같아지도록 잘라 맞췄습니다(8쌍). 블로그의 창틀 옆면·원룸 창틀 두 쌍은 찍은 방향이 반대라 원본 그대로입니다. 새 사진을 넣을 때는 전후를 같은 자리, 같은 높이에서 찍어 주시면 그대로 맞습니다.

## 사진 운영 원칙 (2026.10)
- 같은 사진은 사이트 전체에서 한 곳에만 씁니다. 홈·청소·사례 페이지는 서로 다른 전후 현장을 보여 줍니다.
- 전후 비교 사진은 모두 세로 3:4입니다.
- 휴대폰 카메라 날짜가 찍힌 사진은 아래쪽을 잘라 냈습니다.
- 사업자 정보는 사업자등록증 기준이며, 대표자 이름은 홈페이지에 싣지 않습니다.

## 견적 받는 방식 (2026.10.26)
- 사진을 먼저 받아 견적을 내는 방식은 쓰지 않습니다. 전화·카톡·견적 신청서로 연락을 받고, 상담하며 공간 상태를 여쭤본 뒤 견적을 안내합니다. 사진은 상담 중 필요할 때만 따로 요청합니다.
- 그래서 견적 신청서에는 사진 첨부 칸이 없고, 버튼 문구는 '무료 견적 받기', 작업 과정 2단계는 '상담하고 견적'입니다.
- 사업자 정보에는 업종과 영업시간을 싣지 않습니다.

## 청소 순서 그림 (2026.10.26)
- 청소 페이지 '이 순서로 청소해요'는 입주·이사 / 거주 / 사무실 / 상가 / 준공 다섯 가지로 나뉘어 있고, 위쪽 청소 종류 탭을 고르면 같은 종류로 함께 바뀝니다.
- 순서는 업계 일반 원칙(위→아래, 안쪽→바깥쪽, 물 쓰는 곳 도구 분리)으로 작성했습니다. 실제 현장 순서와 다르면 알려 주세요. (place6.py 의 TYPES 에서 고칩니다.)
