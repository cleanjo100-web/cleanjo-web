# 견적 신청서 → 구글 스프레드시트 연결하기

홈페이지 가격·견적 페이지(`quote.html`)의 신청서를 보내면
구글 스프레드시트 '견적신청' 탭에 한 줄씩 쌓이고, 알림 메일이 옵니다. 서버나 비용은 필요 없습니다.

시트에 쌓이는 칸: 접수번호 · 접수 시각 · 처리 상태 · 이름 · 연락처 · 연락 편한 시간 · 서비스 · 지역 · 시·구 · 공간 종류 · 평수 · 원하는 날짜 · 요청 사항 · 담당자 메모 · 보낸 페이지 · 신청 ID

## 1. 스프레드시트 만들기 (업체 구글 계정으로)
1. sheets.google.com → 빈 스프레드시트. 이름 예: `청소해JO 견적 접수`

## 2. 스크립트 붙이기
1. 스프레드시트 메뉴 **확장 프로그램 → Apps Script**
2. 기본으로 들어 있는 코드를 모두 지우고 `quote-form.gs` 내용을 통째로 붙여 넣은 뒤 저장(💾)
3. 알림 메일 주소 넣기 (둘 중 하나)
   - 코드 맨 위 `var NOTIFY_EMAIL = '';` 따옴표 안에 메일 주소
   - 또는 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성 → `NOTIFY_EMAIL`
4. 위쪽 함수 목록에서 **setup** 을 고르고 **실행**
   - '권한 검토' 창 → 계정 선택 → '고급' → '(안전하지 않음)으로 이동' → 허용
     (내가 만든 스크립트라 구글이 확인하지 않았다는 뜻입니다)
   - 시트에 '견적신청' 탭이 생기고, 연결 확인 메일이 오면 성공
5. (선택) 함수 목록에서 **testPost** 실행 → 시트에 '테스트' 한 줄이 생기고 알림 메일이 오면 정상. 테스트 줄은 지워 주세요.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱**
2. 다음 사용자로 실행: **나** / 액세스 권한이 있는 사용자: **모든 사용자**
3. **배포** → 나오는 `https://script.google.com/macros/s/……/exec` 주소 복사
4. 그 주소를 브라우저에 붙여 열었을 때 '정상적으로 연결되어 있어요'가 보이면 OK

## 4. 홈페이지에 주소 넣기
`js/config.js` 에서
```js
quoteEndpoint: 'https://script.google.com/macros/s/……/exec',
```
저장 → GitHub Desktop 에서 Commit → Push. 1~2분 뒤 홈페이지에서 직접 한 번 신청해 보세요.

## 시트 쓰는 법
- **처리 상태**는 칸을 눌러 목록에서 고릅니다: 신규 → 연락함 → 견적 보냄 → 예약 확정 → 작업 완료 / 진행 안 함 (색이 바뀝니다)
- **담당자 메모** 칸은 자유롭게 쓰세요. 홈페이지에서는 보이지 않습니다.
- 정렬·필터를 써도 되지만, **칸(열)의 순서나 머리글은 바꾸지 마세요.** 새 접수가 엉뚱한 칸에 들어갈 수 있습니다.
- 개인정보 처리방침대로 상담이 끝난 줄은 지우고, 작업을 맡긴 고객은 A/S 기간(청소 14일, 줄눈·탄성 2년 이상)이 지나면 지워 주세요.

## 들어 있는 안전장치
- 사람 눈에 안 보이는 빈칸을 자동 프로그램이 채우면 저장하지 않음(스팸)
- 같은 신청이 두 번 전송돼도 한 번만 저장(신청 ID)
- 같은 번호로 1분 안에 다시 보내면 막음
- `=`, `+`, `-`, `@`로 시작하는 글은 수식으로 실행되지 않게 처리

## 코드를 고친 뒤에는
**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포.** 주소는 그대로라 홈페이지는 고칠 필요가 없습니다.
(새 배포를 또 만들면 주소가 바뀌니 주의)

## 안 될 때
- 신청 후 "보내지 못했어요"가 뜸 → 3번의 액세스 권한이 '모든 사용자'인지, 주소가 `/exec` 로 끝나는지 확인
- 시트에는 들어오는데 메일이 안 옴 → NOTIFY_EMAIL 확인, 스팸함 확인
- `js/config.js` 의 주소가 비어 있으면 신청서는 보이지만, 보내기를 누르면 "전화로 연락 주세요" 안내가 나옵니다.
