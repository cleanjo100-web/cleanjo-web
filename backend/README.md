# 견적 신청서 연결 방법

홈페이지 견적 신청서는 Google 스프레드시트에 쌓이고, 접수될 때마다 메일이 옵니다. (신청서에서 사진 첨부 칸은 뺐습니다. 사진은 상담 중 필요할 때 따로 받습니다.) 서버를 따로 빌릴 필요가 없습니다.

## 1. 시트 만들기
1. 업체 구글 계정으로 새 스프레드시트를 만듭니다. 이름 예: `청소해JO 견적 접수`

## 2. 스크립트 붙이기
1. 스프레드시트에서 **확장 프로그램 > Apps Script**를 엽니다.
2. 기본 코드를 지우고 `quote-form.gs` 내용을 통째로 붙여 넣고 저장합니다.
3. 왼쪽 톱니바퀴(**프로젝트 설정**) > **스크립트 속성**에 `NOTIFY_EMAIL`(알림 받을 메일 주소)을 추가합니다. (`FOLDER_ID`는 사진 첨부를 다시 쓸 때만 필요합니다.)
4. 위쪽 함수 선택에서 `testPost`를 골라 **실행**합니다. 권한 승인 창이 뜨면 허용합니다. 시트에 `견적신청` 탭과 테스트 줄이 생기고 메일이 오면 정상입니다. 테스트 줄은 지워도 됩니다.

## 3. 웹 앱으로 배포
1. **배포 > 새 배포 > 유형: 웹 앱**
2. 실행 사용자: **나**, 액세스 권한: **모든 사용자**
3. 배포 후 나오는 `https://script.google.com/macros/s/.../exec` 주소를 복사합니다.

## 4. 홈페이지에 주소 넣기
`js/config.js`의 `quoteEndpoint: ''` 따옴표 안에 3번 주소를 붙여 넣습니다. 같은 파일에 전화번호(`tel`)와 카카오톡 채널 채팅 주소(`kakao`)도 넣어 주세요.

## 참고
- 스크립트를 고친 뒤에는 **배포 > 배포 관리 > 수정 > 새 버전**으로 다시 배포해야 반영됩니다. 주소는 그대로입니다.
- 접수 시트의 마지막 열 `처리 상태`는 직접 `연락함`, `견적 보냄`, `예약` 등으로 바꿔 가며 쓰시면 됩니다.
- 개인정보 처리방침(`privacy.html`)의 보유 기간과 보호책임자 칸을 채운 뒤 공개하세요.
